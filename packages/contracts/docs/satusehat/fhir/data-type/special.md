# Khusus

Tipe khusus biasanya didefinisikan dan digunakan untuk penggunaan yang khusus/spesifik.

Tabel 1. Tipe Data Khusus

| Tipe Data | Penjelasan |
| --- | --- |
| `CodeableReference` | Tipe data ini merepresentasikan nilai yang merujuk pada beberapa referensi *resource* atau konsep elemen lainnya.  **Struktur JSON:**  ``` {   concept: CodeableConcept (1)   reference: Reference (2) } ```  |  |  | | --- | --- | | **1** | Mereferensi ke konsep *(by class)* | | **2** | Mereferensi ke *resource* lainnya *(by instance)* | |
| `Dosage` | Tipe data ini digunakan untuk memberikan informasi mengenai dosis yang biasanya disajikan dalam bentuk permintaan obat, pengeluaran obat, dan laporan pengobatan.  **Struktur JSON:**  ``` {   sequence: integer (1)   text: string (2)   additionalInstruction: [ CodeableConcept ] (3)   patientInstruction: string (4)   timing: Timing (5)   ?asNeededBoolean: boolean (6)   ?asNeededCodeableConcept: CodeableConcept (7)   site: CodeableConcept (8)   route: CodeableConcept (9)   method: CodeableConcept (10)   doseAndRate: [{ (11)     type: CodeableConcept (12)     ?doseRange: Range (13)     ?doseQuantity: SimpleQuantity (14)     ?rateRatio: Ratio (15)     ?rateRange: Range (16)     ?rateQuantity: SimpleQuantity (17)   }]   maxDosePerPeriod: Ratio (18)   maxDosePerAdministration: SimpleQuantity (19)   maxDosePerLifetime: SimpleQuantity (20) } ```  |  |  | | --- | --- | | **1** | Berisi urutan instruksi dosis. | | **2** | Berisi instruksi dosis obat, contoh: SIG. | | **3** | Berisi instruksi tambahan atau peringatan kepada pasien mengenai obat, contoh: "Diminum setelah makan" atau "dapat menyebabkan kantuk". | | **4** | Berisi instruksi yang berorientasi pada pasien atau konsumen. | | **5** | Berisi informasi kapan obat harus diberikan. | | **6** | Alasan mengapa harus diberikan obat sesuai kebutuhan dengan tipe data `Boolean`. | | **7** | Alasan mengapa harus diberikan obat sesuai kebutuhan dengan tipe data `CodeableConcept`. | | **8** | Bagian tubuh yang akan diberikan obat. | | **9** | Bagaimana obat harus masuk ke dalam tubuh. | | **10** | Teknik pemberian obat. | | **11** | Jumlah obat yang diberikan. | | **12** | Jenis dosis yang ditentukan. | | **13** | Jumlah obat per dosis dengan tipe data `Range`. | | **14** | Jumlah obat per dosis dengan tipe data `SimpleQuantity`. | | **15** | Jumlah obat per satuan waktu dengan tipe data `Ratio`. | | **16** | Jumlah obat per satuan waktu dengan tipe data `Range`. | | **17** | Jumlah obat per satuan waktu dengan tipe data `SimpleQuantity`. | | **18** | Batas maksimal obat per satuan waktu. | | **19** | Batas maksimal obat per pemberian. | | **20** | Batas maksimal obat per seumur hidup pasien | |
| `Extension` | Setiap elemen dalam suatu *resource* atau *data type* selalu menyertakan elemen turunan, seperti `ekstensi` yang dapat muncul beberapa kali.  **Struktur JSON:**  ``` {   *url: uri (1)   ?value: * (2) } ```  |  |  | | --- | --- | | **1** | Berisi URL yang mengidentifikasi arti dari sebuah ekstensi. | | **2** | Nilai dari sebuah ekstensi. | |
| `Meta` | Tipe data ini berisi metadata tentang *resource* yang digunakan.  **Struktur JSON:**  ``` {   versionId: id (1)   lastUpdated: instant (2)   source: uri (3)   profile: [ canonical ] (4)   security: [ Coding ] (5)   tag: [ Coding ] (6) } ```  |  |  | | --- | --- | | **1** | Berisi versi spesifik dari sebuah *identifier*. | | **2** | Kapan versi *resource* terakhir diupdate. | | **3** | Mengidentifikasi darimana *resource* tersebut berasal. | | **4** | Informasi mengenai profil yang digunakan oleh suatu *resource* harus dipatuhi. | | **5** | Berisi label keamanan yang diterapkan ke *resource* ini. | | **6** | Berisi tag-tag yang diterapkan ke *resource* ini | |
| `Narrative` | Tipe data ini berisi ringkasan mengenai suatu *resource* yang dapat dibaca dan dimengerti oleh manusia.  **Struktur JSON:**  ``` {   *status: code (1)   *div: xhtml (2) } ```  |  |  | | --- | --- | | **1** | Berisi code mengenai status dari suatu narasi *(essential clinical and business information)*. | | **2** | Berisi konten xhtml terbatas. | |
| `Reference` | Tipe data untuk menyimpan data yang menunjukan referensi ke resource lainnya. Reference selalu didefinisikan dan direpresentasikan dengan satu alur, yaitu dari resource sumber (*source*) ke resource tujuan (*target/destination*).  **Struktur JSON:**  ``` {   reference: string (1)   type: uri (2)   identifier: identifier (3)   display: string (4) } ```  |  |  | | --- | --- | | **1** | Referensi secara literal. | | **2** | URI dari tipe referensi acuan. | | **3** | Referensi logikal. | | **4** | Deskripsi terkait referensi. |  **Catatan:** Salah satu dari properti `reference`, `identifier`, atau `display` harus didefinisikan (ada nilainya). |
| `xhtml` | Merupakan tipe data yang berisi teks dengan format standar **HTML 4.0** berikut elemen dan atributnya, tetapi didalamnya tidak boleh ada elemen seperti: *head, body*, referensi ke *stylesheet* eksternal, *scripts, forms, base/link/xlink, frames, iframes* dan *objects*. |
